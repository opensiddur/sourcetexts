Absolute/tmp and worktree paths identify the actual reviewed inputs; reproduce them from the committed evidence and parent revision when rerunning. exporter-note-diffs.json preserves the exact unified diffs as JSON strings; this keeps required patch context whitespace out of ordinary source-file whitespace checks.
